# Password Generator 

# About the Project
This is a simple Password Generator project made using Python. It generates a random password based on the length entered by the user.

The generated password contains lowercase letters, uppercase letters, numbers, and special characters to make it stronger.

# Features
* User can enter the desired password length.
* Generates random passwords.
* Includes lowercase letters (a-z).
* Includes uppercase letters (A-Z).
* Includes numbers (0-9).
* Includes special characters (@, #, $, %, &, !).
* Shuffles the characters to make the password more random.
* Handles invalid input using try-except.

# Technologies Used
* Python
* Random Module

# How to Run the Project

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Create a Python file named `password_generator.py`.
4. Copy the project code into the file.
5. Open the terminal in VS Code.
6. Run the following command:

bash
python password_generator.py
